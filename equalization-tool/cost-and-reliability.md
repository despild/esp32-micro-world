# 비용·안정성·지속 사용 계획

2026-11-11 사용자 요구: 비용을 최소화하면서 안정성과 지속성을 확보. 여기서 지속성은 배터리 사용시간, 장기 내구성, 수리·유지보수 가능성을 함께 고려합니다. 아직 실물로 검증한 성능이나 확정 견적은 없습니다.

## 우선 구성

| 항목 | 기본 제안 | 비용과 안정성의 관계 |
|---|---|---|
| MCU / OLED | 보유 ESP32-C3 mini와 OLED 재사용 | 두 부품의 추가 구매비 0원. 실제 전원 회로 확인 필요 |
| 통신 | ESP32 내장 BLE, Wi-Fi는 기본 비활성 | 추가 무선 모듈 불필요. 화면과 BLE 처리는 센서 취득과 분리 |
| 센서 | XGZP6897D 양방향 ±10 kPa 모듈부터 검증 | I²C로 ADC·증폭기 부품을 줄임. 범위 충족 여부는 별도 확인 |
| 조작 | 택트스위치 2개, 전원 전환 스위치 1개 | 기계식으로 간단하게 구성 |
| 배터리 | 출처와 사양이 확인되는 보호회로 포함 1셀 약 1,000 mAh | 과방전·과전류 보호와 충전 허용치 확인 |
| 충전 | 충전전류 설정 가능한 TP4056 계열, OFF에서 충전 | 충전 중 사용을 제외해 전원 분배 모듈 비용 절감 |
| 전압 변환 | 보유 보드 입력에 맞춘 모듈 | 최대 출력 광고보다 최저 배터리 전압에서의 실제 부하 대응 확인 |
| 공기 경로 | 교체형 호스/팁, 포집부, 적합한 필터, 당김 방지 | 센서 교체 비용과 고장 가능성을 줄이기 위한 설계 |

현재 보유 부품을 재사용하는 것이 1대 제작에서는 우선입니다. 새 보드를 구매할 때만 충전회로 내장 XIAO 등과 전체 전원부 비용을 비교합니다. 내장 충전 기능이 있는 보드라도 ON/OFF·충전 경로는 따로 확인해야 합니다.

## 센서 선택의 조건

±10 kPa는 −100~+100 hPa이며, 비용 우선 시험 후보입니다. 모든 이퀄라이징 동작을 담기에 충분하다고 검증된 수치가 아닙니다. 실제 파형이 범위에 근접하거나 포화되면 더 넓은 양방향 제품으로 변경합니다. ±20–25 kPa는 여유를 둔 대안이며 생리적 정상범위나 훈련 목표값이 아닙니다.

XGZP6897D는 제조사에서 저비용 용도를 표방하지만, 최신 세대/품번의 실제 소량 도착 가격은 미확정입니다. 제품명만 같은 모듈, 한쪽 방향 전용 제품, 다른 I²C 세대를 혼동하지 않습니다. 제조사 주문 예시 `XGZP6897DC010KPDPN`을 기준으로 실제 공급품의 데이터시트를 확인합니다. [CFSensor 제품](https://cfsensor.com/product/xgzp6897d/), [V3.3 문서](https://cfsensor.com/wp-content/uploads/2026/09/XGZP6897D-Pressure-Sensor-V3.3.pdf)

정확한 압력값과 장기 안정성은 센서 사양·교정·응축 시험으로 확인합니다. 매회 영점 조정은 오프셋을 줄이는 절차이며 전체 범위의 오차나 손상된 센서를 복구하지 않습니다. Honeywell ABP2의 적합한 액체 매체 옵션은 습기 시험을 통과하지 못할 때 비교할 대안으로 남깁니다. 싼 센서를 반복 교체하는 비용까지 고려합니다.

## 충전 회로에서 줄일 수 있는 비용

기본 제안은 물리 스위치로 **ON=기기 사용 / OFF=충전 가능**을 선택하는 방식입니다. 배터리와 충전기와 부하를 항상 병렬로 연결하지 않고, 사용/충전 경로를 전환합니다. [연결 설계안](design-notes.md)

TP4056는 충전전류가 줄어드는 것을 기준으로 충전을 종료하므로 부하 전류가 함께 흐르면 종료 판단에 영향을 줄 수 있습니다. 기본안은 이 조건을 경로 분리로 피하도록 설계합니다. [제조사 데이터시트](https://www.toppwr.com/uploadfile/file/20240307/65e993d6379ea.pdf), [Microchip 전원 분배 설계](https://www.microchip.com/en-us/application-notes/an1149)

2026-11-11 확인한 가격 비교 예시는 아래와 같습니다. **배송·세금 제외 제조사 웹 표시가이며, 국내 도착 견적이나 확정 구매 목록이 아닙니다.**

| [Seeed XIAO ESP32C3](https://www.seeedstudio.com/Seeed-XIAO-ESP32C3-p-5431.html) | US$4.99 | 새 MCU 보드 구매 시 비교 대상. 보유 OLED 보드의 단순 추가 부품은 아님 |

위 충전기 두 제품은 기능이 다릅니다. 일반 TP4056 모듈은 더 저렴한 판매품도 있지만 충전전류, 보호회로 유무, USB-C CC 구성, 부품 출처와 배선 자료 확인이 필요합니다. 동일 외형만으로 검증된 제품이라고 판단하지 않습니다. 저가 모듈 구매가는 아직 확정하지 않았습니다.

1,000 mAh 후보 팩은 200 mA 충전부터 검토합니다. 팩의 허용 전류가 최종 기준이며 용량만으로 정하지 않습니다. 충전 속도를 높이기 전에 케이스 내부 온도와 충전 종료를 실측합니다. 충전기 IC의 열 제한 기능이 배터리 셀의 온도 감시를 대신하지는 않습니다.

## 오래 쓰기 위해 유지할 설계

- 센서보다 낮은 위치에 물방울 포집부를 배치하고 호스/필터는 교체 가능하게 설계. 소수성 필터가 수증기까지 제거하는 것은 아니므로 센서 내부 결로 시험 필요.
- 센서 포트에 호스의 당김이나 꺾임이 직접 전달되지 않게 케이스에 고정. 배터리와 센서 모듈은 수리 가능한 연결 사용.
- 실제 사용 전·후 영점과 반복 파형을 기록하고 공기압 기준기로 여러 압력점 확인. 반복 습기 노출 후 드리프트·복귀 여부 비교.
- 저전압에서 무선 송신과 화면 갱신이 겹칠 때 재부팅이 없는지 확인. 평상시 평균 전류와 순간 부하를 따로 측정.
- 기록은 폰에서 보관하고, 기기 설정은 변경할 때만 플래시에 저장. 매 샘플을 내부 플래시에 쓰는 방식은 초기안에서 제외.
- 화면 밝기·갱신 빈도를 줄이고 미사용 시 화면/센서 전원을 관리. 그래프 표시를 줄여도 원래 센서 취득 주기와 시간 정보는 유지.
- 기기 기본 측정은 휴대폰·인터넷 없이 동작하게 설계. BLE가 끊겨도 로컬 화면을 유지하고 폰 기록에는 공백을 표시.

사용시간과 센서 수명을 현재 숫자로 보장할 수는 없습니다. 같은 부품이라도 보드 전원 LED, 승압기, 화면, BLE 설정, 습기 노출에 따라 달라지므로 완성 회로에서 실측합니다.

## 다음 선정 기준

구매 전 정확한 양방향 센서 품번과 소량 재고를 먼저 확인하고, 배터리·전원·호스 부품을 합친 배송비 포함 견적을 비교합니다. 초기 1대에 필수 부품만 구입하고 범위·습기·충전 시험을 통과한 뒤 동일 품번을 반복 사용합니다. 더 큰 화면, 별도 배터리 잔량 IC, 전용 PCB는 실제 필요가 확인될 때 추가합니다.
