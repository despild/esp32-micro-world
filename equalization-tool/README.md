# Equalization Tool · 휴대용 이퀄라이징 압력 측정기

ESP32와 호스 연결형 압력센서로 만드는 육상 이퀄라이징 연습용 기기입니다. 현재 단계는 **부품 조사와 설계 제안**이며, 회로 제작·펌웨어·휴대폰 앱·실측 검증은 아직 진행하지 않았습니다.

조사 기준일: 2026-11-11, Asia/Seoul.

## 요구사항

- 호스 연결이 쉬운 센서로 입 또는 코 쪽의 상대압 측정.
- 기기 화면에 압력 표시. 작은 택트스위치로 화면 전환과 기능 설정.
- 별도의 물리 온오프 스위치.
- 가능하면 BLE로 휴대폰에서 실시간 확인 및 기록.
- USB 보조배터리로 시험 가능하고, 최종적으로 충전식 리튬이온/리튬폴리머 배터리 사용.
- 기존 `esp32-micro-world` 저장소의 `equalization-tool/` 아래에서 관리.

## 제안 구성

| 부분 | 1차 제안 | 선정 상태 |
|---|---|---|
| MCU | 현재 사용 중인 ESP32-C3 mini 재사용 | BLE 지원. 실제 보드 회로와 여유 GPIO 확인 필요 |
| 압력센서 | XGZP6897D 계열, I²C·호스 포트·양압 0–20 kPa 옵션 | 저비용 시제품 후보. 정확한 품번·세대·재고 확인 후 확정 |
| 양방향 측정 대안 | 같은 계열 ±10 kPa 또는 Honeywell ABP2 ±25 kPa | 음압 필요 여부와 양압 상한에 따라 선택 |
| 화면 | 보유 0.42인치 OLED로 숫자 표시부터 시작 | 독립 사용 시 0.96–1.3인치 128×64 OLED 검토 |
| 조작 | 소형 순간동작 택트스위치 2개 | 화면/이동, 선택/기록. 1개 구성도 가능 |
| 전원 | 보호회로 포함 1셀 3.7 V, 1,000 mAh 안팎 배터리 | 완충 4.2 V 계열. 충전 허용전류 확인 |
| 충전 | BQ24074 기반 전원 분배 지원 모듈 | 충전과 기기 구동을 분리하기 위한 후보 |
| 온오프 | 충전 모듈 LOAD 뒤의 슬라이드 스위치 | 기기 OFF 상태에서도 충전 가능하게 설계 |
| 전압 변환 | 보드 입력에 맞춘 레귤레이터 | 현재 보드 회로 확인 전 직결 핀을 지정하지 않음 |

센서 상세 사양과 근거는 [하드웨어 조사](hardware-research.md), 연결 방식과 버튼·BLE·전원 동작은 [설계안](design-notes.md)에 정리했습니다. 표의 범위는 **기기의 측정 범위**이며 사람에게 권장하는 이퀄라이징 압력이 아닙니다.

## 진행 순서

1. 정확한 보드 모델, 센서 주문 옵션, 배터리/충전 전류를 확정.
2. USB 전원으로 센서·호스·화면·버튼의 기본 동작 확인.
3. 공기압 기준기와 비교하여 영점, 누설, 반복성, 응답 지연 확인.
4. BLE 송수신과 휴대폰 그래프 구현.
5. 배터리·충전·전원 스위치 통합 후 충전 중/배터리 동작·대기전류 실측.
6. 케이스와 호스 고정부 제작.

추후 실제 구현 파일은 이 폴더 아래 `firmware/`, `hardware/`, `app/`, `enclosure/`에 추가합니다. 현재는 구현하지 않은 코드나 배선도를 완성품으로 표시하지 않습니다.
