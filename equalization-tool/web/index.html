연결과 측정 안내

Wi-Fi EQ-C3 · 비밀번호 eqtest32 · http://192.168.4.1. 인터넷 없는 Wi-Fi 연결을 유지하고 Android Chrome의 로컬 네트워크 권한을 허용하세요.

교정 전에는 ADC 원시값 또는 영점을 뺀 RAW가 표시됩니다. HX710B 압력 모드는 목표 40 samples/s이며 브라우저는 약 100 ms마다 묶어서 받습니다. 연결이 끊기거나 ADC가 포화하면 그래프 선이 끊깁니다. 음압과 40 kPa 초과는 이 모듈의 검증 범위가 아닙니다. 표시 범위는 사람에게 권장하는 압력이 아닙니다.
